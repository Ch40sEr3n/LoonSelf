# LoonSelf

个人 Loon 配置与规则发布仓库，基于 [YohakuSama/loonkit](https://github.com/YohakuSama/loonkit) 精简。当前保留 25 个策略组、28 个上游规则集及 6 条本地规则。Lumen 固定直连，GitHub Raw 跟随 GitHub 策略。

## 使用

在 Loon 中导入固定配置链接：

```text
https://raw.githubusercontent.com/Ch40sEr3n/LoonSelf/main/LoonKit.lcf
```

公开配置不含机场订阅、节点和 MITM 证书。导入后自行添加订阅；已在使用的设备应先导出备份，核对配置更新时的覆盖选项。远程规则内容更新可直接刷新规则订阅，策略或本地规则变化需要更新主配置。

## 更新方式

每天北京时间 08:23，由私有仓库执行完整更新：

1. 从上游同一提交读取正式发布清单和配置，核对摘要。
2. 校验并保存已批准的 28 份规则，更新私有主配置中的规则地址，保留订阅、节点、策略及本地规则。
3. 将输入配置归档到私有仓库，保存更新后的完整私有配置。
4. 生成脱敏副本，移除订阅、节点、MITM 和私人引用；通过检查后发布到本仓库。

本公开仓库只接收脱敏结果并执行只读校验，不再独立定时拉取上游。修改个人策略或规则时，应修改私有主配置；直接修改本仓库的生成文件会被后续发布覆盖。

自动合并仅针对已批准的规则内容和规则地址。上游增删策略、规则缺失、归属改变或规则内容大幅变化会停止更新，等待核对。未知配置区块、未批准的 URL 或疑似凭据也会阻止公开发布，保留已有公开版本。

定时任务可能延迟。令牌过期或校验失败时，在私有仓库的 Actions 查看运行结果。

## 文件

| 路径 | 用途 |
| --- | --- |
| `LoonKit.lcf` | 脱敏配置订阅入口 |
| `config/base.lcf` | 同次发布的脱敏源，用于一致性检查 |
| `config/sync.json` | 本次发布批准的上游规则清单 |
| `rules/upstream/` | 经过校验的上游规则副本 |
| `state/upstream.json` | 上游版本、提交和规则摘要 |
| `LICENSES/` | 上游许可与来源声明 |

本地只读检查要求 Python 3.11 或以上，无第三方依赖：

```sh
python3 -m unittest discover -s tests -v
python3 scripts/sync_rules.py --check
```

当前网络诊断插件要求 Loon 3.5.1（983）及以上，尚未在真实设备上验证本个人版本。
